# WebKonneK

<img width="1600" height="1000" alt="image" src="https://github.com/user-attachments/assets/67a67d93-ea7a-4fd9-9f31-fa04ecdf7eb4" />

This project is a personal hands-on journey to explore how system layers interact while learning C. 
The goal is to build a lightweight monitoring tool that displays real-time resource usage in a browser.
I'll be updating this README.md as the project develops.

*Please note that this is a learning project, which will continue to grow as I acquire new skills.*
*Work on fedora kde plasma, debian 13, further test needed for compatibility.*

# Setup

**First Step :**

Clone the repository : ```git clone [repo]``` --> (_Click on ```<code>``` box on top of project files/directories and then copy link_)

**Second Step :**

Go to the repository directory : ```cd WebKonnek```

**Final Step :**

Run the make file : ```make run```

**Then :**

_http://localhost:2222 --> password ```admin``` (or ```WEBKONNEK_PASSWORD=[your_password] make run```)_
